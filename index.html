Bước 1: Tạo Google Sheet
Sheet sẽ là kho lưu trữ chung của toàn bộ leads YTK Global.
1

Mở link này trong tab mới

https://sheets.newclick để mở
2

Đặt tên file là "YTK GLOBAL CRM"

Click vào "Untitled spreadsheet" → gõ YTK GLOBAL CRM → Enter
3

Đổi tên tab thành "Leads"

Chuột phải vào tab "Sheet1" → Rename → gõ Leads → Enter
Bước 2: Cài Apps Script
Apps Script là cầu nối giữa CRM và Google Sheets. Copy/paste, không cần hiểu code.
1

Mở Apps Script

Trong Google Sheet → Extensions (Tiện ích mở rộng) → Apps Script
2

Xóa code cũ, dán code mới vào

3

Lưu lại

Ctrl+S (hoặc Cmd+S trên Mac)
Bước 3: Bảo mật, Deploy & kết nối
Đặt mã bảo mật riêng, deploy để Apps Script chạy được từ internet, rồi dán URL + mã vào đây.
1

Đặt mã bảo mật (Script Properties)

Bên trái màn hình Apps Script → biểu tượng Project Settings → cuộn xuống Script Properties → Add script property
Property: SECRET_TOKEN · Value: 1 chuỗi khó đoán tự đặt (VD 20-30 ký tự bất kỳ) → Save
Mã này chỉ nằm trong Apps Script của bạn — không lưu trong code public.
2

Nhấn Deploy → New deployment (Triển khai mới)

3

Cài đặt

• Type / Loại: Web app / Ứng dụng web
• Execute as: Me / Tôi
• Who has access: Anyone / Mọi người
→ Nhấn Deploy
4

Cấp quyền (Authorize)

Nếu thấy cảnh báo → Advanced / Nâng cao → Go to YTK... → Allow / Cho phép
5

Dán URL + mã bảo mật vào đây

URL dạng: https://script.google.com/macros/s/.../exec · Mã bảo mật = đúng giá trị SECRET_TOKEN vừa đặt ở bước 1

Chia sẻ cho team

📥 Nhập lead từ Excel

Chọn file Excel (.xlsx/.xls) hoặc CSV chứa danh sách học sinh. Hệ thống tự nhận diện cột theo tên tiếng Việt — kể cả file song ngữ Hàn-Việt như file trường ĐH hay gửi. Bước sau anh/chị xem lại & sửa mapping nếu đoán sai, trước khi lưu thật vào CRM.

Lọc dòng theo cột (tuỳ chọn — VD file gộp nhiều NV thì lọc lấy đúng 1 người)
Khớp cột file → field CRM
Áp dụng cho tất cả dòng được nhập
Xem trước — 0 dòng, đã tick 0
⚠️ Dòng tô cam là nghi trùng (tên/SĐT đã có trong CRM, hoặc trùng trong chính file này) — mặc định KHÔNG tick, anh/chị tự xem rồi tick lại nếu chắc chắn là người khác.
